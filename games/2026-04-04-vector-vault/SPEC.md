# ベクトルヴォルト
- Date: 2026-04-04
- Slug: vector-vault

## 企画（Producer）
- 1メカニクス：タップ位置で3列の「開放ライン」を切り替え、同列に来た青キューブだけを回収する。
- フック（1行）：一手遅れると赤トラップが刺さる、列切り替え一本勝負の60秒。
- 勝ち条件：60秒でできるだけ高スコアを獲得する。
- 負け条件：時間切れ（ライフ制は無し、赤キューブ接触で減点）。
- 1プレイ時間：60秒以内

## ルール（Designer）
- フィールドは左・中・右の3列で、開放ラインは常に1列だけ有効。
- ステージをタップした列がそのまま開放ラインになる。
- 上から落ちる青キューブが開放ライン下端に到達すると +1 点。
- 赤キューブが開放ライン下端に到達すると -2 点（0未満にはならない）。
- 60秒終了時点のスコアを結果とし、ハイスコアを保存する。

## UI（Designer）
- ボタン：START/RETRY 1個
- 表示：スコア / 残り時間 / ハイスコア / 現在列
- 操作：タップ（pointerdown）で列選択

## 難易度（Designer）
- 0-30秒：落下速度は低め、赤比率25%、同時出現は少なめ。
- 30-45秒：落下速度上昇、赤比率35%、2個同時出現が増える。
- 45-60秒：落下速度さらに上昇、赤比率45%、連続出現で判断猶予が短い。
