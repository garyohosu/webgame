# スカイラインパイク
- Date: 2026-06-27
- Slug: skyline-pike

## 企画（Producer）
- 1メカニクス：自動で左右に往復するランチャーの位置に合わせ、タップで真上へパイクを射出する
- フック（1行）：狙いは自動、決断だけが自分。青いドローンを抜き、赤い地雷を見送る60秒。
- 勝ち条件：60秒のあいだに青いターゲットをできるだけ多く撃ち抜き、ハイスコアを更新する
- 負け条件：時間切れ、または赤いターゲット誤射でスコアを落とす
- 1プレイ時間：60秒以内

## ルール（Designer）
- ランチャーは画面下で左右に自動往復し、プレイヤーはタップでその真上にパイクを撃つ。
- 青いスカイドローンを撃ち抜くと加点、赤いマインを撃つと減点になる。
- パイクは短いクールダウン後に再発射でき、何も当たらない空撃ちは減点なし。
- 連続で青を当てるとコンボが伸び、得点が少しずつ増える。
- 30秒以降は速度と出現密度、終盤は赤ターゲット比率も上がる。

## UI（Designer）
- ボタン：スタート、再挑戦
- 表示：スコア / 残り時間 / ハイスコア / Charge / Combo
- 操作：タップ

## 難易度（Designer）
- 0-30秒：ターゲット速度は穏やか、青中心で狙いやすい導入
- 30-45秒：横移動速度と出現頻度を上げ、2レーン同時処理を増やす
- 45-60秒：赤マイン比率を上げ、ランチャー往復も速めて判断を忙しくする
