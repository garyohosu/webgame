# スレッドスパイア
- Date: 2026-07-11
- Slug: thread-spire

## 企画（Producer）
- 1メカニクス：往復する針の位置でタップし、縦の糸筋を一瞬だけ走らせて青い粒をまとめて縫い取る
- フック（1行）：一列まとめ取りの爽快感と、赤い結び目を巻き込む怖さが同時に走る。
- 勝ち条件：60秒のあいだに青いルーメン粒をできるだけ多く縫い取り、ハイスコアを更新する
- 負け条件：時間切れ、または赤いノットを糸筋に巻き込んで減点する
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面下を左右に往復する針は自動で動き、プレイヤーは位置を見てタップするだけ。
- タップすると針の真上に細い糸筋が短時間だけ走り、その列にいる粒をまとめて判定する。
- 青いルーメン粒を縫うと加点し、連続成功でコンボ倍率が少しずつ伸びる。
- 赤いノットを巻き込むと減点し、コンボが切れて短いクールダウン中は次の糸筋を撃てない。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 状態
- 操作：タップ

## 難易度（Designer）
- 0-30秒：針の往復は穏やかで、青粒が多めに流れる導入フェーズ
- 30-45秒：落下速度と横揺れが増し、赤いノット比率も上がって列読みが必要になる
- 45-60秒：針の移動が速くなり、出現密度と赤比率がさらに上がる終盤構成
