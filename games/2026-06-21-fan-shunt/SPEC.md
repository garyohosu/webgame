# ファンシャント
- Date: 2026-06-21
- Slug: fan-shunt

## 企画（Producer）
- 1メカニクス：タップで送風ファンの向きを LEFT / RIGHT に切り替え、青いシードだけを側面ポケットへ吹き込み、赤いアッシュを避ける。
- フック（1行）：画面下の風向きひとつで拾うか捨てるかが決まる、反射神経と欲張りのせめぎ合い。
- 勝ち条件：60秒のあいだに青いシードをできるだけ多くポケットへ送り込み、ハイスコアを更新する。
- 負け条件：時間切れで終了。赤いアッシュを吸い込むと減点され、青いシードを落とすとコンボが切れる。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 落ちてくる粒子は青いシードか赤いアッシュで、下部の送風帯に入ると現在の風向き側へ吸われる。
- プレイ中に画面をタップすると送風ファンの向きが LEFT / RIGHT で切り替わる。
- 青いシードを風で側面ポケットへ運べば加点、連続成功中はコンボぶんだけ得点が伸びる。
- 赤いアッシュを吸い込むと減点。青いシードを取り逃がして床に落とすとコンボは 0 に戻る。
- 30秒と45秒を境に落下速度・出現密度・赤比率・横揺れが上がる。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / 風向き
- 操作：タップで LEFT / RIGHT 切り替え

## 難易度（Designer）
- 0-30秒：青シード中心で、落下テンポも緩やか。風向き切り替えの感覚を掴む導入。
- 30-45秒：左右同時に見張る必要が出て、赤アッシュが混ざり始める中盤。
- 45-60秒：横揺れと赤比率が増し、欲張って吹くと誤吸引しやすい終盤。
