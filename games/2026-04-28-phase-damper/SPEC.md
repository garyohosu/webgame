# フェーズダンパー
- Date: 2026-04-28
- Slug: phase-damper

## 企画（Producer）
- 1メカニクス：タップでダンパー開閉を切り替え、青パルスだけを吸収して赤パルスを受け流す。
- フック（1行）：開けるほど稼げるが、欲張ると赤を拾って崩れる“欲張り制御”ゲーム。
- 勝ち条件：60秒終了時にスコアを最大化する。
- 負け条件：時間切れ以外のゲームオーバーなし（赤誤吸収は減点）。
- 1プレイ時間：60秒以内

## ルール（Designer）
- タップでダンパー状態を CLOSED / OPEN で切り替える。
- パルスは上から落下し、判定ライン通過時に OPEN なら吸収判定。
- 青パルス吸収で加点、赤パルス吸収で減点。
- CLOSED 中はすべて通過し、取り逃しペナルティはなし。
- 60秒終了時に最終スコアを表示し、ハイスコア更新を判定する。

## UI（Designer）
- ボタン：スタートボタン、リトライボタン（ゲーム終了後表示）
- 表示：スコア / 残り時間 / ハイスコア / 現在ダンパー状態
- 操作：タップ（pointerdown）でダンパー切替

## 難易度（Designer）
- 0-30秒：低速・低密度、赤比率25%
- 30-45秒：速度と密度上昇、赤比率35%
- 45-60秒：さらに加速、赤比率45%
