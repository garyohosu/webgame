# ポラリティ・パニック
- Date: 2026-04-01
- Slug: polarity-panic

## 企画（Producer）
- 1メカニクス：タップで受け皿の極性（＋ / －）を即時切替し、同極の粒子だけを吸収する
- フック（1行）：1タップで世界のルールが反転する、60秒の極性ジャッジ。
- 勝ち条件：60秒終了時にスコア20点以上
- 負け条件：なし（ただし逆極吸収で減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 上から「＋」「－」粒子が落下してくる。
- 画面下のコアは現在極性を持ち、タップで「＋」「－」を切り替える。
- 同じ極性の粒子をコアで受けると +1 点。
- 逆の極性を受けると -1 点。
- 粒子を取り逃がしても減点はない。

## UI（Designer）
- ボタン：STARTボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア / 現在極性
- 操作：タップ（game area の pointerdown で極性切替）

## 難易度（Designer）
- 0-30秒：落下速度低め、同時出現3個まで
- 30-45秒：落下速度中、同時出現4個まで、出現間隔短縮
- 45-60秒：落下速度高、同時出現5個まで、逆極粒子の比率増加
