# シルクシェルフ
- Date: 2026-07-22
- Slug: silk-shelf

## 企画（Producer）
- 1メカニクス：タップした高さへ発光シェルフを即移動させ、青いドロップだけを棚に乗せて左の回収ポッドへ流す
- フック（1行）：一枚の棚を上下させるだけで、青を救って赤を見送る空中仕分けが成立する。
- 勝ち条件：60秒のあいだに青いドロップをできるだけ多く棚へ受けて左ポッドへ送り、ハイスコアを更新する
- 負け条件：時間切れ、または青を落として減点し、赤を棚に当てて失点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面タップで発光シェルフの高さを上下に動かし、上から落ちる青いドロップと赤いエンバーの通り道を読む。
- 青がシェルフに触れると左へ滑走し、そのまま回収ポッドへ届けば加点とコンボになる。
- 赤がシェルフに当たると棚が焦げて失点し、コンボが切れる。
- 赤は棚に触れず下のベントへ落ちれば小加点、青を落としてしまうと減点になる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 棚の高さ
- 操作：タップ

## 難易度（Designer）
- 0-30秒：落下テンポは穏やかで、青多めかつ速度差が小さい導入
- 30-45秒：赤の比率と落下速度が上がり、棚の上下移動を細かく求める
- 45-60秒：出現間隔が詰まり、赤が高速化して一手遅れがそのまま失点につながる
