# ネオンオービット・ガード
- Date: 2026-03-27
- Slug: neon-orbit-guard

## 企画（Producer）
- 1メカニクス：タップでシールド回転方向を反転し、リング上で迎撃位置を合わせる
- フック（1行）：逆回転の一手で流れが変わる、60秒の軌道読み反射ゲーム。
- 勝ち条件：60秒終了時にできるだけ高スコアを獲得する
- 負け条件：時間切れ（ライフ制なし）
- 1プレイ時間：60秒以内

## ルール（Designer）
- シールドはリング上を自動回転し、タップで回転方向が反転する。
- 青いスパークをシールドで受けると +10 点。
- 赤いノイズをシールドで受けると -12 点（最低 0 点）。
- スパーク／ノイズは外周から中心へ直進し、中心に到達すると消える。
- 60秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：Start / Retry（終了後表示）
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）で回転方向反転

## 難易度（Designer）
- 0-30秒：低速出現、青スパーク比率高め（約75%）
- 30-45秒：出現間隔短縮、移動速度上昇、赤ノイズ比率増加（約35%）
- 45-60秒：さらに高速化、同時出現数増加、赤ノイズ比率増加（約42%）
