# グリントプール
- Date: 2026-07-18
- Slug: glint-pool

## 企画（Producer）
- 1メカニクス：タップした地点に一瞬だけ吸い込みの水紋を発生させ、青いグリントだけをまとめて引き寄せて赤いスパークを避ける
- フック（1行）：狙うのはキャラではなく、水面そのもの。
- 勝ち条件：60秒のあいだに青いグリントをできるだけ多く吸い込み、ハイスコアを更新する
- 負け条件：時間切れ、または赤いスパークを巻き込んで減点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面内を漂う青いグリントと赤いスパークを見て、欲しい群れの中心へタップする。
- タップした位置に短時間だけ吸引プールが開き、半径内の粒子をまとめて判定する。
- 青いグリントを吸うと加点とコンボ加算、赤いスパークを吸うと減点されてコンボが切れる。
- プールには短いクールダウンがあるので、密集タイミングと場所の見極めが重要になる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / チャージ
- 操作：タップ

## 難易度（Designer）
- 0-30秒：粒子速度は穏やかで、青多めの導入フェーズ
- 30-45秒：出現密度と移動速度が上がり、クールダウン管理が必要になる
- 45-60秒：赤比率が増え、粒子の揺れ幅も強まって欲張りタップが危険になる
