# ジャイアセントリー
- Date: 2026-07-02
- Slug: gyre-sentry

## 企画（Producer）
- 1メカニクス：タップで周回ガードの回転方向を反転し、青いコメットだけを迎撃する
- フック（1行）：守る場所はひとつ、触っていい色もひとつ。反転一発で流れを取り返す60秒。
- 勝ち条件：60秒のあいだに青いコメットをできるだけ多く迎撃し、ハイスコアを更新する
- 負け条件：時間切れ、または赤いマインを迎撃して減点・スタンする
- 1プレイ時間：60秒以内

## ルール（Designer）
- ガードはコアの周囲を自動回転し、画面タップで回転方向だけを反転できる。
- 青いコメットがガード帯を通過する瞬間に重なると得点とコンボが増える。
- 赤いマインを迎撃すると減点され、コンボが切れて短いスタンが発生する。
- 青を取り逃がしてコアに到達させるとミスになり、コンボが途切れる。
- 終盤ほど飛来速度と出現密度が上がり、赤比率も増える。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 方向
- 操作：タップ

## 難易度（Designer）
- 0-30秒：青多め、飛来速度ゆるめで反転タイミングを覚える導入
- 30-45秒：ガード回転と飛来速度を上げ、連続迎撃しやすい角度判断を要求する
- 45-60秒：赤マイン比率と同時出現率を増やし、欲張ると崩れる終盤にする
