# フェーズポケット
- Date: 2026-03-22
- Slug: phase-pocket

## 企画（Producer）
- 1メカニクス：タップで受け皿（ポケット）の位相を左/中/右に切り替え、同じ位相のオーブだけを回収する。
- フック（1行）：落下速度が上がる終盤で「一手遅い」が即失点になる、位相スイッチ集中ゲーム。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得する。
- 負け条件：時間切れ（ゲームオーバー）。
- 1プレイ時間：60秒以内

## ルール（Designer）
- オーブは左・中・右の3レーンいずれかを落下し、色で位相を示す（青=左、紫=中、黄=右）。
- ポケットはタップごとに 左→中→右→左… と巡回切り替えする。
- オーブが下端判定線に到達した瞬間、ポケット位相と一致なら +1点。
- 不一致なら -1点（最低0点）で、ミス演出を表示。
- 60秒経過で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタートボタン1つ（プレイ中は非表示）。
- 表示：スコア / 残り時間 / ハイスコア / 現在位相ラベル。
- 操作：タップ（`pointerdown`）で位相切替。

## 難易度（Designer）
- 0-30秒：落下速度ゆっくり、出現間隔長め。
- 30-45秒：落下速度を上げ、同時に落ちる感覚を強める。
- 45-60秒：さらに速度上昇、出現間隔を短縮して判断猶予を削る。
