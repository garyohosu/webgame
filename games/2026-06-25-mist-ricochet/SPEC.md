# ミストリコシェ
- Date: 2026-06-25
- Slug: mist-ricochet

## 企画（Producer）
- 1メカニクス：タップで中央ディフレクターの角度を UP / DOWN に反転し、青いミスト滴を上層リザーバーへ、赤いスス滴を下層ベントへ弾き分ける。
- フック（1行）：落ちる物を受けるのではなく、当てて跳ね返す角度読みで仕分ける60秒。
- 勝ち条件：60秒のあいだに青いミスト滴をできるだけ多く上層リザーバーへ導き、ハイスコアを更新する。
- 負け条件：時間切れで終了。青を下へ落とす、または赤を上へ弾くと失点する。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 滴は左のノズルから中央ディフレクターへ向かって飛び込み、現在の角度に応じて上か下へ弾かれる。
- プレイ中に画面をタップするとディフレクター角度が UP / DOWN に切り替わる。
- 青いミスト滴を上層リザーバーへ送ると加点し、連続成功でコンボが伸びる。
- 赤いスス滴を下層ベントへ落とせば安全処理。青を下へ、赤を上へ送ると失点してコンボが切れる。
- 30秒と45秒で飛来速度・出現頻度・赤比率が上がり、反転の先読みが必要になる。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / 角度 / コンボ
- 操作：タップで UP / DOWN 切り替え

## 難易度（Designer）
- 0-30秒：飛来速度は控えめ、青多め。跳ね返し角と上下出口の位置を覚える導入。
- 30-45秒：赤スス滴が増え、連続で上下反転する判断が求められる中盤。
- 45-60秒：飛来テンポと弾速が最大化し、1回の遅れで複数ミスにつながる終盤。
