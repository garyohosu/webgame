# ハーバーシフト
- Date: 2026-07-23
- Slug: harbor-shift

## 企画（Producer）
- 1メカニクス：タップで上下2レーンのハーバー配置を瞬時に入れ替え、青い舟を受けて赤い障害舟を外す
- フック（1行）：一回のスワップだけで、救助港と排水路の役割がひっくり返る判断の速さが気持ちいい。
- 勝ち条件：60秒のあいだに青い舟をできるだけ多くハーバーへ着岸させ、ハイスコアを更新する
- 負け条件：時間切れ、または青舟を排水路へ流し赤舟を着岸させて失点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- タップするたびに、上レーンと下レーンのハーバー配置が入れ替わる。
- 左から流れてくる青い舟は、ハーバーがあるレーンで受けると加点とコンボになる。
- 赤い障害舟は、排水路があるレーンへ流せば小加点、ハーバーで受けると失点する。
- 青い舟を排水路へ流した場合も失点し、コンボが切れる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 港の位置
- 操作：タップ

## 難易度（Designer）
- 0-30秒：舟の速度は控えめで、青多めの導入フェーズ
- 30-45秒：速度と赤比率が上がり、連続スワップが必要になる
- 45-60秒：出現間隔が詰まり、上下の読み違いが即失点につながる
