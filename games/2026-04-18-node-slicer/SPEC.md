# ノードスライサー
- Date: 2026-04-18
- Slug: node-slicer

## 企画（Producer）
- 1メカニクス：自動で左右往復するスキャンラインの位置でタップ斬撃を発動する
- フック（1行）：狙うのは“今このX座標”だけ、待ちと一撃の60秒。
- 勝ち条件：60秒終了時にハイスコア更新、または自己ベストに近い高得点を獲得
- 負け条件：赤ノード誤斬りや青ノード取り逃しでスコアが伸びない
- 1プレイ時間：60秒以内

## ルール（Designer）
- スキャンラインはフィールドを左右往復し続ける。
- タップすると、その瞬間のスキャンライン位置で縦スライス判定が発生する。
- 判定幅内の青ノードは加点、赤ノードは減点。
- 青ノードが画面下に到達すると取り逃しとして減点。
- 60秒経過でゲーム終了、ハイスコアを localStorage に保存する。

## UI（Designer）
- ボタン：START/RETRY ボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：ノード落下速度ゆるめ、赤ノード比率低め
- 30-45秒：落下速度上昇、同時出現数と赤ノード比率が増加
- 45-60秒：さらに高速化、出現間隔短縮で密度上昇
