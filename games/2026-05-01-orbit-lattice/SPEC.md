# Orbit Lattice
- Date: 2026-05-01
- Slug: orbit-lattice

## 企画（Producer）
- 1メカニクス：タップで回転する格子リングの位相を1ステップ進め、落下ノードの通過スロット色を合わせる。
- フック（1行）：一手遅れると連鎖崩壊する、位相合わせの60秒パズル反射。
- 勝ち条件：60秒終了時にスコアを最大化し、ハイスコア更新を狙う。
- 負け条件：即時ゲームオーバーはなし（ミスマッチで減点）。
- 1プレイ時間：60秒以内

## ルール（Designer）
- タップごとにリング位相が「青→黄→桃→青…」と進む。
- 上から落ちるノードは3色のいずれかで、判定ライン到達時にリング位相と一致すると得点。
- 不一致なら減点され、コンボがリセットされる。
- ノード取り逃しでもコンボはリセットされるが減点はなし。
- 60秒で終了し、ハイスコアを localStorage に保存する。

## UI（Designer）
- ボタン：スタートボタン×1
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ

## 難易度（Designer）
- 0-30秒：落下速度ゆるめ、同時出現1個中心。
- 30-45秒：落下速度1.2倍、出現間隔短縮。
- 45-60秒：落下速度1.45倍、低確率で2連続出現。
