# ハロードリフト
- Date: 2026-06-23
- Slug: halo-drift

## 企画（Producer）
- 1メカニクス：タップで収穫リングを INNER / OUTER に切り替え、青いオーブだけをリングで拾って赤いノイズを通す。
- フック（1行）：一瞬先に来る軌道を読んで、内外2本のリングを切り替え続ける宇宙釣り。
- 勝ち条件：60秒のあいだに青いオーブをできるだけ多く回収し、ハイスコアを更新する。
- 負け条件：時間切れで終了。赤いノイズを拾うと減点、青いオーブを中心へ逃すとコンボが切れる。
- 1プレイ時間：60秒以内

## ルール（Designer）
- オーブは外周から中心へ流れ込み、青は回収対象、赤は触れてはいけないノイズ。
- プレイ中に画面をタップすると収穫リングが INNER / OUTER で切り替わる。
- アクティブなリングに青いオーブが触れた瞬間に加点し、連続成功でコンボが伸びる。
- 赤いノイズをリングで拾うと減点。青いオーブを中心まで通すとコンボが 0 に戻る。
- 30秒と45秒を境に流入速度・出現密度・赤比率・軌道の揺れが上がる。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / リング状態
- 操作：タップで INNER / OUTER 切り替え

## 難易度（Designer）
- 0-30秒：青オーブが多く、軌道も素直。内外の距離感を覚える導入。
- 30-45秒：赤ノイズが増え、曲線的な流れが混ざって先読みが必要になる中盤。
- 45-60秒：流入ペースと旋回が強まり、内外の連続切替を要求する終盤。
