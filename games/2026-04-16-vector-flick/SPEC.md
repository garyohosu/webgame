# ベクターフリック
- Date: 2026-04-16
- Slug: vector-flick

## 企画（Producer）
- 1メカニクス：タップ位置で自機の移動先レーン（左/中/右）を即時指定する
- フック（1行）：1タップの判断で「回収」か「衝突」かが即決する、短時間集中の3レーン反応ゲーム。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得する
- 負け条件：時間切れ（ライフ制なし、誤操作は減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- プレイヤーは画面下部の3レーン（左/中/右）を移動して落下オブジェクトを処理する。
- 画面の左1/3・中1/3・右1/3をタップすると、そのレーンへ即時移動する。
- 青いコアを取ると +10 点、赤いノイズに当たると -12 点（最低 0 点）。
- 取り逃した青コアは -4 点。赤ノイズの取り逃しは減点なし。
- 制限時間 60 秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：START/RESTART ボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：落下速度低め、赤比率 25%、出現間隔 620ms
- 30-45秒：落下速度中、赤比率 35%、出現間隔 470ms
- 45-60秒：落下速度高、赤比率 45%、出現間隔 340ms
