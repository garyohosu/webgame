# フリップパッド・レスキュー
- Date: 2026-03-16
- Slug: flip-pad-rescue

## 企画（Producer）
- 1メカニクス：タップで左右パッドの上下位置を同時フリップし、落下ポッドを安全側で受け止める
- フック（1行）：1タップで盤面の重力感覚が反転する、判断ミス即失点の60秒レスキュー。
- 勝ち条件：60秒終了時にできるだけ高スコアを獲得する
- 負け条件：即ゲームオーバーはなし（誤キャッチで減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 上から落ちるポッドは「救助（青）」と「危険（赤）」の2種類。
- 画面下の左右パッドは、タップするたびに「上段/下段」を同時に切り替える。
- 青ポッドをパッドで受けると +1 点、取り逃すと -1 点。
- 赤ポッドをパッドで受けると -2 点、取り逃しは 0 点。
- 60秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）でパッド位置フリップ

## 難易度（Designer）
- 0-30秒：落下速度ゆっくり、出現間隔長め、赤ポッド少なめ
- 30-45秒：落下速度と出現数を増やし、赤ポッド比率アップ
- 45-60秒：さらに高速化し、同時落下の頻度を上げる
