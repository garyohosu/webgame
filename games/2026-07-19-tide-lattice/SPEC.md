# タイドラティス
- Date: 2026-07-19
- Slug: tide-lattice

## 企画（Producer）
- 1メカニクス：タップで中央ラティスの傾きを反転し、落ちてくる粒子の流れ先を左の採集湾か右の廃棄ベントへ切り替える
- フック（1行）：群れを丸ごと迎えるか、まとめて見送るかを一枚の格子で決める。
- 勝ち条件：60秒のあいだに青いルーン粒をできるだけ多く採集し、ハイスコアを更新する
- 負け条件：時間切れ、または赤いスラグ粒を採集湾へ流して減点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- 上から落ちる青いルーン粒と赤いスラグ粒を見て、中央ラティスをタップで `/` と `\` に反転する。
- 粒子がラティスに触れると、そのときの傾きに沿って左の採集湾か右の廃棄ベントへ滑っていく。
- 青を採集湾へ入れると加点とコンボ加算、赤を採集湾へ入れると減点されてコンボが切れる。
- 赤を廃棄ベントへ逃がすと小加点、青を廃棄ベントへ流すと取り逃しになってコンボが切れる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 流向
- 操作：タップ

## 難易度（Designer）
- 0-30秒：落下速度は穏やかで、青多めの基本ウェーブ
- 30-45秒：出現密度と滑走速度が上がり、赤の混ざる群れが増える
- 45-60秒：赤比率と同時出現数が増え、反転判断を遅らせると一気に崩れる
