# ウェーブスタンプ
- Date: 2026-07-17
- Slug: wave-stamp

## 企画（Producer）
- 1メカニクス：上下に往復するスキャン帯へタップを合わせ、横一閃のスタンプで青い欠片だけをまとめて刻んで赤いノイズを避ける
- フック（1行）：狙うのは点ではなく、往復する一本の高さそのもの。
- 勝ち条件：60秒のあいだに青い欠片を多く刻み、ハイスコアを更新する
- 負け条件：時間切れ、または赤いノイズを巻き込んで減点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- スキャン帯は画面内を上下に往復し続け、プレイヤーは現在の高さだけを見てタイミングを取る。
- タップすると現在の高さに横一線のスタンプが走り、帯の中にいる欠片をまとめて判定する。
- 青い欠片を刻むと加点とコンボが増え、赤いノイズを刻むと減点されてコンボが切れる。
- 欠片は左右から滑り込むので、密集した高さまで待ってから叩くほど効率が上がる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / レーン
- 操作：タップ

## 難易度（Designer）
- 0-30秒：往復速度は穏やかで、青多めの導入フェーズ
- 30-45秒：出現密度と往復速度が上がり、待ち撃ちより先読みが必要になる
- 45-60秒：赤比率が上がり、帯幅も少し狭まって欲張りショットが危険になる
