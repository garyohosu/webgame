# ペタルパラソル
- Date: 2026-07-03
- Slug: petal-parasol

## 企画（Producer）
- 1メカニクス：タップでパラソルを OPEN / FOLD に切り替え、青い花粉だけを受け止める
- フック（1行）：開けば全部を拾う。だからこそ、赤い棘が混じる一瞬を見送れるかが勝負になる。
- 勝ち条件：60秒のあいだに青いブルームをできるだけ多く受け止め、ハイスコアを更新する
- 負け条件：時間切れ、または赤いソーンを開いたパラソルで受けて減点する
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面タップで中央パラソルを OPEN / FOLD に切り替える。
- OPEN 中に青いブルームが傘へ触れると加点し、連続成功でコンボ倍率が上がる。
- OPEN 中に赤いソーンを受けると減点し、コンボが切れる。
- FOLD 中は安全にやり過ごせるが、青いブルームを落とすと取り逃がしになってコンボが切れる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 状態
- 操作：タップ

## 難易度（Designer）
- 0-30秒：落下速度は控えめ、青比率高めで OPEN/FOLD の判断に慣れる導入
- 30-45秒：出現間隔を詰めて左右の揺れを増やし、早めの切り替え判断を要求する
- 45-60秒：赤比率と落下速度が上がり、欲張って開き続けると崩れる終盤構成
