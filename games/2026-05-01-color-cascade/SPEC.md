# Color Cascade
- Date: 2026-05-01
- Slug: color-cascade

## 企画（Producer）
- 1メカニクス：落ちてくる色球を、同じ色の受け皿にタップで切り替えて受ける
- フック（1行）：1タップで盤面全体の色が入れ替わる、判断連打の60秒パズル
- 勝ち条件：60秒でできるだけ多く正しくキャッチしてスコアを伸ばす
- 負け条件：色違いで受けるとライフ減少、ライフ0で即終了
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面上から色球（赤/青/緑）が1つずつ落下する。
- 画面下の受け皿はタップで「赤→青→緑」の順に全体色が切り替わる。
- 色球と受け皿の色が一致したら+1点、ミスするとライフ-1。
- ライフは3。0になるとその時点でゲーム終了。
- 60秒経過時にゲーム終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：Start / Retry、受け皿切替用のプレイエリアタップ
- 表示：スコア / 残り時間 / ハイスコア / ライフ
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：落下速度ゆっくり、出現間隔も長め。
- 30-45秒：落下速度を約1.25倍、出現間隔を短縮。
- 45-60秒：落下速度を約1.45倍、出現間隔をさらに短縮。
