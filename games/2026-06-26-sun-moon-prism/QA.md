# QA - 2026-06-26 サンムーンプリズム

## 対象
- スマホ縦画面（想定幅 360-430px）
- タップ操作

## チェック結果
- 操作性：画面内の `pointerdown` で即時にプリズムが反転し、スタート後の主操作は1タップ1反転で分かりやすい。ボタン周りとゲーム面を分離して誤爆を抑えた。
- 表示：ヘッダー、HUD、キャンバス、下部操作列が1画面に収まり、`100dvh` と safe-area padding で縦持ち表示を維持できる構成。
- パフォーマンス：描画は単一 canvas と `requestAnimationFrame` ベース。パーティクル数も小さく、60秒プレイ想定では軽量。

## バグ
- なし

## 改善提案（最大3つ）
1. 成功時に左右受け皿のアイコン演出を増やし、正解フィードバックをさらに強くする。
2. 終盤だけ 2 個同時落下のレアパターンを追加すると、切り替え判断の山場を作りやすい。
3. サウンドが必要なら Web Audio API で短いクリック音と成功音を足せる。
