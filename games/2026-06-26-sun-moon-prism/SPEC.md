# サンムーンプリズム
- Date: 2026-06-26
- Slug: sun-moon-prism

## 企画（Producer）
- 1メカニクス：タップで中央プリズムの傾きを LEFT / RIGHT に反転し、落下オーブの進路を左右どちらかへ曲げる
- フック（1行）：シアンは月鉢へ、アンバーは陽炉へ。1タップで両方の運命をまとめてねじ曲げる60秒。
- 勝ち条件：60秒のあいだに正しい受け皿へできるだけ多くのオーブを送り込み、ハイスコアを更新する
- 負け条件：時間切れ、または誤ルーティングや取りこぼしでスコアを落とす
- 1プレイ時間：60秒以内

## ルール（Designer）
- オーブは上から落ち、中央プリズムに触れると現在の傾きに応じて左か右へ弾かれる。
- シアンの月オーブは左の月鉢、アンバーの陽オーブは右の陽炉へ入れると加点。
- 逆側へ送ると減点、画面下へ取りこぼしても減点。
- タップするたびにプリズムの傾きが LEFT / RIGHT で反転する。
- 連続成功でストリークが伸び、1個あたりの得点が少しずつ増える。

## UI（Designer）
- ボタン：スタート、再挑戦
- 表示：スコア / 残り時間 / ハイスコア / Prism / Streak
- 操作：タップ

## 難易度（Designer）
- 0-30秒：落下速度と出現間隔は穏やか、色の偏りも小さい
- 30-45秒：出現間隔を短縮し、オーブの横揺れと速度を強化
- 45-60秒：連続出現と高速落下で切り替え判断を忙しくする
