# アークラッチ
- Date: 2026-04-23
- Slug: arc-latch

## 企画（Producer）
- 1メカニクス：タップで受け皿レーンを循環切替し、落下物を仕分ける
- フック（1行）：1タップで運命が変わる、レーン先読み60秒。
- 勝ち条件：60秒終了時にスコアをできるだけ伸ばす
- 負け条件：時間切れ（赤ノイズ接触で減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- タップ（pointerdown）するたびに受け皿が左→中央→右へ巡回する。
- 上から青パルス（+10）と赤ノイズ（-12）が落下する。
- 受け皿と同じレーンで接触したオブジェクトだけ判定される。
- 取り逃した青は0点、赤を受けるとスコア減点になる。
- 60秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：Start / Restart（1ボタン運用）
- 表示：スコア / 残り時間 / ハイスコア / 現在レーン
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：落下速度標準、出現間隔 760ms
- 30-45秒：落下速度 1.2倍、出現間隔 620ms
- 45-60秒：落下速度 1.45倍、出現間隔 500ms、赤ノイズ比率上昇
