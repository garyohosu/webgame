# スタンプマーシュ
- Date: 2026-03-11
- Slug: stamp-marsh

## 企画（Producer）
- 1メカニクス：沼に浮かぶ安全な印章だけをタップし、危険なひび割れ印章を避けながら連鎖を伸ばす。
- フック（1行）：浮いて沈む一瞬の印章を見極め、沼のリズムに乗って連打と判断をつなぐ60秒。
- 勝ち条件：60秒以内にできるだけ高いスコアを獲得する。
- 負け条件：安全印章の取り逃がし、または危険印章の誤タップでライフが0になる。
- 1プレイ時間：60秒以内

## ルール（Designer）
- フィールドには安全な印章と危険なひび割れ印章が順次浮かび、数秒で沈む。
- 安全な印章をタップすると +1 点、連続成功でコンボ倍率が少し伸びる。
- 安全な印章を取り逃がすか、危険印章をタップするとライフ -1 でコンボが切れる。
- ライフが0になるか、60秒経過でゲーム終了。
- ハイスコアは端末に保存し、次回プレイ時に表示する。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア / ライフ / コンボ
- 操作：タップ（pointerdown）で印章を選択

## 難易度（Designer）
- 0-30秒：出現間隔はゆるめ、安全印章中心で寿命も長い。
- 30-45秒：出現間隔短縮、危険印章の混入率と同時出現数が増える。
- 45-60秒：寿命がさらに短くなり、終盤は二連続出現で判断を急がせる。
