# レーンフリップ・ラッシュ
- Date: 2026-04-25
- Slug: lane-flip-rush

## 企画（Producer）
- 1メカニクス：タップでキャッチャーのレーン位置を左→中→右へ巡回切替する
- フック（1行）：1タップで未来の落下位置まで読ませる、瞬間判断の60秒ラッシュ。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得する
- 負け条件：赤ノイズを受け続けてスコアを落とす（ゲームオーバーは無し）
- 1プレイ時間：60秒以内

## ルール（Designer）
- タップ（pointerdown）するたび、下部キャッチャーが左→中→右の順に移動する。
- 上から落ちる青ノードを同じレーンで受けると +10 点。
- 赤ノイズを同じレーンで受けると -12 点（最低 0 点）。
- 取り逃した青ノードは -3 点。
- 60秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（ゲームエリア全体の pointerdown でレーン切替）

## 難易度（Designer）
- 0-30秒：落下速度ふつう、赤ノイズ少なめ（約20%）
- 30-45秒：落下速度上昇、赤ノイズ増加（約30%）
- 45-60秒：さらに高速化、同時出現率と赤ノイズ率上昇（約38%）
