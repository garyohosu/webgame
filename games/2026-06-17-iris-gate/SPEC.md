# アイリスゲート
- Date: 2026-06-17
- Slug: iris-gate

## 企画（Producer）
- 1メカニクス：タップで中央アイリスを OPEN / SHUT に切り替え、落下物を通すか弾くかだけを判断する。
- フック（1行）：青は通し、赤は閉じる。中央のアイリス一枚で60秒を捌く即断ゲーム。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得し、ハイスコアを更新する。
- 負け条件：時間切れで終了。赤パルスを通すか青パルスを弾くと減点。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面タップで中央アイリスを OPEN / SHUT に切り替える。
- 青パルスがアイリスラインを通過すると加点し、連続成功でコンボ倍率が上がる。
- 赤パルスは SHUT の状態で弾くとセーフ、OPEN のまま通すと減点になる。
- 青パルスを SHUT で弾くと減点になり、コンボも切れる。
- 30秒と45秒を境に落下速度、出現密度、赤比率が上がる。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / アイリス状態＋コンボ
- 操作：タップ（画面内どこでも OPEN / SHUT 切替）

## 難易度（Designer）
- 0-30秒：単発中心、落下はゆるめ、赤比率は低い。
- 30-45秒：2連続出現が増え、落下速度と赤比率が上がる。
- 45-60秒：群れ出現と高速落下が重なり、開閉判断の猶予が短くなる。
