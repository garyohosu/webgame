# グロウサイロ
- Date: 2026-08-31
- Slug: glow-silo

## 企画（Producer）
- 1メカニクス：4本の発光サイロを列ごとにタップし、上端の収穫口に届いた青い粒だけを回収する
- フック（1行）：見た目は静かな倉庫管理なのに、終盤は複数列の青粒回収タイミングが一気に噛み合わなくなる。
- 勝ち条件：60秒で青い粒をできるだけ多く回収し、ハイスコアを更新する
- 負け条件：時間切れ、または赤い粒を誤回収して失点し続ける
- 1プレイ時間：60秒以内

## ルール（Designer）
- 4本のサイロから青粒と赤粒が下から上へ流れ、上端の収穫口を順に通過する。
- 収穫口に近い粒がある列をタップすると、その先頭粒を即座に処理する。
- 青粒を処理すると得点とコンボが伸び、赤粒を処理すると失点してコンボが切れる。
- 青粒を取り逃すとコンボが切れるが、赤粒は触らず見送れば失点しない。
- 時間経過で上昇速度、出現密度、赤粒比率が上がる。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / フェーズ
- 操作：タップ

## 難易度（Designer）
- 0-30秒：青粒中心、上昇速度は緩めで1列ずつ判断しやすい
- 30-45秒：2列以上が同時に収穫口へ届き、赤粒も混ざり始める
- 45-60秒：全列が高密度で回り、赤粒比率と上昇速度が上がって即断が必要になる
