# パルスレーン・キーパー
- Date: 2026-03-19
- Slug: pulse-lane

## 企画（Producer）
- 1メカニクス：タップで3レーンのアクティブゲートを切り替え、正しいレーンでのみパルスを回収する。
- フック（1行）：次に来る光を読む「先読み」と瞬時のタップ切替が気持ちいい60秒。
- 勝ち条件：60秒終了時にスコアを最大化する。
- 負け条件：即時ゲームオーバーはなし（ミスで減点し、最終スコア勝負）。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 上から降るパルスは青（GOOD）と赤（BAD）の2種類。
- 画面下の3ゲートのうち、光っている1つだけが回収判定を持つ。
- タップするとアクティブゲートが左→中央→右→左…の順に切り替わる。
- GOODを正しいゲートで受けると+10点、取り逃しは0点。
- BADを受けると-8点、取り逃したBADは+2点（回避ボーナス）。

## UI（Designer）
- ボタン：スタートボタン 1個、リトライボタン 1個
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）でゲート切替

## 難易度（Designer）
- 0-30秒：出現間隔 700ms、落下速度 140px/s、BAD比率 25%
- 30-45秒：出現間隔 560ms、落下速度 185px/s、BAD比率 35%
- 45-60秒：出現間隔 460ms、落下速度 225px/s、BAD比率 42%
