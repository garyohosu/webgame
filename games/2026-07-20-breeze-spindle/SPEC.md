# ブリーズスピンドル
- Date: 2026-07-20
- Slug: breeze-spindle

## 企画（Producer）
- 1メカニクス：タップで中央スピンドルの回転方向を反転し、触れた粒子を左の採集ポッドか右の排熱ベントへ弾き分ける
- フック（1行）：一度の反転で群れの運命がまとめて変わる、風向き裁きの60秒。
- 勝ち条件：60秒のあいだに青いルーメン粒をできるだけ多く採集し、ハイスコアを更新する
- 負け条件：時間切れ、または赤いスパークを左ポッドへ流して減点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- 上から落ちる青いルーメン粒と赤いスパークを見て、中央スピンドルをタップで LEFT / RIGHT 回転に切り替える。
- 粒子がスピンドル圏に入ると、その時点の回転方向に応じて左右どちらかへ強く弾かれる。
- 青を左の採集ポッドへ入れると加点とコンボ加算、赤を左へ入れると減点されてコンボが切れる。
- 赤を右の排熱ベントへ逃がすと小加点、青を右へ流すと取り逃しになってコンボが切れる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 回転方向
- 操作：タップ

## 難易度（Designer）
- 0-30秒：落下速度は穏やかで、青多めの単発ウェーブ中心
- 30-45秒：出現密度と弾き速度が上がり、赤の混ざる群れが増える
- 45-60秒：赤比率と同時出現数が増え、反転の遅れがそのまま失点につながる
