# グロウモス
- Date: 2026-07-08
- Slug: glow-moth

## 企画（Producer）
- 1メカニクス：タップでランタンを一瞬だけ発光させ、青いモスだけを引き寄せる
- フック（1行）：欲張って灯すほど赤い灰蛾まで寄ってくるので、短い閃きの見極めがそのままスコアになる。
- 勝ち条件：60秒のあいだに青いグロウモスをできるだけ多く回収し、ハイスコアを更新する
- 負け条件：時間切れ、または赤いアッシュモスをランタンへ引き込んで減点する
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面タップでランタンが短時間だけ点灯し、近くのモスを中心へ引き寄せる。
- 点灯中に青いグロウモスがランタン圏へ入ると加点し、連続成功でコンボ倍率が伸びる。
- 点灯中に赤いアッシュモスを引き込むと減点し、コンボが切れる。
- 点灯しない時間は安全だが、青いモスを逃がすとコンボが途切れる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 発光状態
- 操作：タップ

## 難易度（Designer）
- 0-30秒：出現数は控えめで青比率も高く、短い点灯リズムに慣れる導入
- 30-45秒：モスの横流れと出現テンポが上がり、早めの点灯判断が必要になる
- 45-60秒：赤比率と移動速度が上昇し、まとめ取りを狙うほど事故りやすい終盤構成
