# ナンバーシーブ
- Date: 2026-03-31
- Slug: number-sieve

## 企画（Producer）
- 1メカニクス：表示ルール（PRIME / COMPOSITE）に合う数字チップだけをタップで回収する
- フック（1行）：同じ数字でも「今のルール」で価値が反転する、60秒の瞬間判別ゲーム。
- 勝ち条件：60秒終了時にスコア20以上
- 負け条件：60秒終了時にスコアが20未満
- 1プレイ時間：60秒以内

## ルール（Designer）
- 数字チップ（1〜20）が上から落下する。
- 上部の TARGET が PRIME（素数）か COMPOSITE（合成数）かを示す。
- TARGET は一定時間ごとに自動で切り替わる。
- TARGET に合う数字をタップすると +1、合わない数字をタップすると -1。
- 60秒終了時のスコアで結果判定し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタートボタン（リスタート兼用）
- 表示：スコア / 残り時間 / ハイスコア / 現在TARGET
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：落下速度ゆっくり、同時出現2〜3個、TARGET切替12秒
- 30-45秒：落下速度1.2倍、同時出現3〜4個、TARGET切替10秒
- 45-60秒：落下速度1.45倍、同時出現4〜5個、TARGET切替8秒
