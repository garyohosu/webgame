# エコーブルーム
- Date: 2026-05-22
- Slug: echo-bloom

## 企画（Producer）
- 1メカニクス：タップで中央から衝撃波リングを放ち、近づく青い種をちょうど重なった瞬間に咲かせる
- フック（1行）：押す場所ではなく押す瞬間だけで盤面を制御する、1拍遅れが命取りの60秒パルスゲーム。
- 勝ち条件：60秒終了までにできるだけ多くの青い種を咲かせて高得点を取る
- 負け条件：なし（赤いノイズ種を巻き込むと減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 種は画面の外周から中央へ向かって流れ込む。
- 画面タップ（pointerdown）で中央から衝撃波リングを1発放つ。
- リングが青い種に重なると花が開いて+12点、近い連続成功でチェイン倍率が伸びる。
- リングが赤いノイズ種に触れると-15点、チェインは0に戻る。
- 種を中央まで通してしまうと0点でチェインが切れる。60秒で終了。

## UI（Designer）
- ボタン：START / REPLAY（終了時）
- 表示：スコア / 残り時間 / ハイスコア / CHAIN
- 操作：タップでパルス発射

## 難易度（Designer）
- 0-30秒：種の流入は穏やか、赤比率18%、パルスの再使用待ちは短め
- 30-45秒：移動速度1.2倍、赤比率28%、同時出現数が増える
- 45-60秒：移動速度1.4倍、赤比率36%、大きめの群れが増えてタイミング要求が上がる
