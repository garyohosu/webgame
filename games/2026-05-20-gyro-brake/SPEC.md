# ジャイロブレーキ
- Date: 2026-05-20
- Slug: gyro-brake

## 企画（Producer）
- 1メカニクス：回転インジケーターをタップで一瞬ブレーキし、安全角度で止める
- フック（1行）：止める勇気より、止めない勇気がスコアを伸ばす。
- 勝ち条件：60秒でハイスコア更新
- 負け条件：時間切れ（即ゲームオーバー要素はなし、ミスで減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 針は常に回転し、タップで短時間だけ減速する。
- 青アーク上でタップすると成功で加点＋コンボ加算。
- 赤アーク上でタップすると減点＋コンボ切断。
- 何もない角度でタップすると小減点。
- 60秒終了時にスコアを確定し、ハイスコアを保存する。

## UI（Designer）
- ボタン：START / RESTART
- 表示：スコア / 残り時間 / ハイスコア / コンボ
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：回転速度低め、青アーク幅広め
- 30-45秒：回転速度上昇、赤アーク増加
- 45-60秒：回転速度さらに上昇、青アーク縮小
