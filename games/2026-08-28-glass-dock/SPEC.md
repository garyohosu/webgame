# グラスドック
- Date: 2026-08-28
- Slug: glass-dock

## 企画（Producer）
- 1メカニクス：タップしたレーンへ受け皿付きの桟橋を滑らせ、青い雫だけを受けて赤い火花を避ける
- フック（1行）：指先で次の着地先を決めるだけなのに、終盤は連続横移動の読みが熱い。
- 勝ち条件：60秒のあいだに青い雫をできるだけ多く回収し、ハイスコアを更新する
- 負け条件：時間切れ、または赤い火花を受け止めて失点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面下の4レーンのうち、タップしたレーンへ桟橋が自動でスライドする。
- 上から落ちる青い雫を桟橋で受けると加点し、コンボが伸びる。
- 赤い火花を桟橋で受けると失点し、コンボが切れる。
- 取り逃した青い雫は減点なしだが、テンポが崩れてハイスコアを伸ばしにくい。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / レーン
- 操作：タップ

## 難易度（Designer）
- 0-30秒：落下速度は穏やかで、青い雫中心の導入フェーズ
- 30-45秒：落下速度と出現密度が上がり、左右の振り回しが増える
- 45-60秒：赤比率も上がり、連続で逆サイドへ滑らせる判断が必要になる
