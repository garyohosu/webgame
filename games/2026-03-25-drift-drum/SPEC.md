# ドリフトドラム
- Date: 2026-03-25
- Slug: drift-drum

## 企画（Producer）
- 1メカニクス：回転するニードルがセーフゾーンに入った瞬間だけタップする
- フック（1行）：待つ勇気と一撃の判断を60秒で何度も迫る“間”のゲーム。
- 勝ち条件：60秒でできるだけ多くの成功タップを積む
- 負け条件：時間切れ（ミスは減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- スタート後、中央ドラムの針が回転し続ける。
- 針が青いセーフアーク内にある時にタップすると +1 点。
- セーフ外でタップすると -1 点（0点未満にはならない）。
- 成功するとセーフアークの位置が再配置される。
- 60秒終了時に最終スコアを表示し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：回転速度ゆるめ、セーフアーク幅広め（約56度）
- 30-45秒：回転速度アップ、セーフアーク幅中（約44度）
- 45-60秒：回転速度さらにアップ、セーフアーク幅狭め（約32度）
