# シグナルウィーブ
- Date: 2026-05-13
- Slug: signal-weave

## 企画（Producer）
- 1メカニクス：タップで3本の受信ラインを巡回し、同ラインの青シグナルだけを拾う
- フック（1行）：1タップの判断遅れが即失点に繋がる、先読み仕分けの60秒。
- 勝ち条件：60秒終了時にスコアを最大化する
- 負け条件：ゲームオーバーはなく、赤取得や青取り逃しで減点
- 1プレイ時間：60秒以内

## ルール（Designer）
- タップするたびに受信カーソルが「左→中→右→左…」と巡回する。
- 上から落ちる青シグナルをカーソルと同じレーンで受けると加点。
- 赤ノイズを受けると減点、青シグナルを床に落としても減点。
- 30秒以降は落下速度上昇、45秒以降は出現密度と赤比率が上がる。
- 60秒で自動終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：Startボタン（開始時のみ）
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）でレーン巡回

## 難易度（Designer）
- 0-30秒：落下速度ふつう、同時出現は最大2個
- 30-45秒：落下速度を約1.2倍、赤ノイズ比率を上昇
- 45-60秒：落下速度を約1.45倍、同時出現最大3個で高密度化
