# コアカラー・スナップ
- Date: 2026-03-15
- Slug: core-color-snap

## 企画（Producer）
- 1メカニクス：中心コアの色と同じ色の飛来オーブだけをタップ回収する
- フック（1行）：色合わせの判断とオーブ迎撃を同時に回す、60秒の集中アクション。
- 勝ち条件：60秒終了時にできるだけ高スコアを獲得する
- 負け条件：時間切れ（ゲームオーバーはなく60秒で必ず終了）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面中央に3色のコアがあり、タップで色を切り替える。
- 外周からオーブが中心へ向かって移動する。
- コアと同色のオーブをタップすると +1 点。
- 異色オーブをタップすると -1 点。
- 同色オーブを取り逃がして中心に到達させると -2 点。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（コア切替・オーブ回収ともに pointerdown）

## 難易度（Designer）
- 0-30秒：出現間隔 820ms、移動速度は標準
- 30-45秒：出現間隔 620ms、移動速度 1.2倍
- 45-60秒：出現間隔 470ms、移動速度 1.45倍
