# シルクカイト
- Date: 2026-07-09
- Slug: silk-kite

## 企画（Producer）
- 1メカニクス：往復するカイトから、タップで短時間だけ捕獲テザーを垂らす
- フック（1行）：ラインを伸ばせるのは一瞬だけなので、青い灯種を欲張るほど赤いカッターも絡みやすい。
- 勝ち条件：60秒のあいだに青いスレッドシードをできるだけ多く回収し、ハイスコアを更新する
- 負け条件：時間切れ、または赤いスパインカッターをテザーに引っかけて減点する
- 1プレイ時間：60秒以内

## ルール（Designer）
- カイトは画面上部を自動往復し、タップするとその場から短時間だけ縦テザーを下ろす。
- 上昇してくる青いスレッドシードがテザーに触れると加点し、連続成功でコンボが伸びる。
- 赤いスパインカッターをテザーで引っかけると減点し、コンボが途切れる。
- テザーには短いクールダウンがあり、連打しすぎると空振りしやすい。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / テザー状態
- 操作：タップ

## 難易度（Designer）
- 0-30秒：カイト速度と出現密度は穏やかで、青比率も高い導入フェーズ
- 30-45秒：上昇速度と横流れが増し、テザーの置きどころを先読みする必要が出る
- 45-60秒：赤比率とカイト速度がさらに上がり、欲張り回収が事故に変わりやすい終盤構成
