# グリッドスタンピード
- Date: 2026-04-24
- Slug: grid-stampede

## 企画（Producer）
- 1メカニクス：自動で巡回するカーソル位置に合わせてタップでスタンプし、青セルを抜く
- フック（1行）：動く照準を「待って叩く」だけなのに、後半は赤セル混入で一気に判断が痺れる
- 勝ち条件：60秒終了時にスコアをできるだけ伸ばす（ハイスコア更新を狙う）
- 負け条件：時間切れ（赤セル誤タップで減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 5x6 のグリッド上をカーソルが自動巡回する
- タップすると「現在のカーソル位置」のセルをスタンプ判定する
- 青セルを踏むと +1、赤セルを踏むと -2、空セルは 0
- 判定後、そのセルは消え、一定間隔で新しい青/赤セルが補充される
- 60秒で終了し、ハイスコアを保存する

## UI（Designer）
- ボタン：スタートボタン（1つ）
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：カーソル遅め、青多め、赤は少量
- 30-45秒：カーソル速度上昇、赤セル比率を増やす
- 45-60秒：カーソル最速、赤セル出現頻度アップで誤タップリスク増加
