# デュアルハース
- Date: 2026-06-18
- Slug: dual-hearth

## 企画（Producer）
- 1メカニクス：タップで炉床を FROST / FLARE に切り替え、落下物を着地の瞬間だけ正しい温度で受ける。
- フック（1行）：冷やすか、燃やすか。床の温度ひとつで60秒を捌く即断アクション。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得し、ハイスコアを更新する。
- 負け条件：時間切れで終了。色と温度が噛み合わない着地は減点になり、コンボが切れる。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面タップで炉床の温度を FROST / FLARE に反転する。
- 青い欠片は FROST、橙の火種は FLARE で受けると加点し、連続成功でコンボ倍率が伸びる。
- 色と逆の温度で受けると減点され、コンボは 0 に戻る。
- 同時に複数落ちることがあり、直前の並びを見て切り替えタイミングを決める。
- 30秒と45秒を境に落下速度、同時出現率、フェイント配置が増える。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / 現在モード＋コンボ
- 操作：タップ（プレイ中の画面内で温度切替）

## 難易度（Designer）
- 0-30秒：単発中心。落下はゆるめで、同色連打を多めにして慣らす。
- 30-45秒：2連続や左右ずらしが増え、落下速度と交互配列が強くなる。
- 45-60秒：同時落下と色交互のフェイントが増え、切替猶予がかなり短くなる。
