# ノヴァスネア
- Date: 2026-07-02
- Slug: nova-snare

## 企画（Producer）
- 1メカニクス：タップで中心から拡がるノヴァリングを放ち、接触した青い粒子だけを捕まえる
- フック（1行）：一撃は広い。でも赤まで巻き込む。欲張りと見送りの判断だけで60秒を走り切る。
- 勝ち条件：60秒のあいだに青いグリントをできるだけ多く捕まえ、ハイスコアを更新する
- 負け条件：時間切れ、または赤いスパイクをリングに巻き込んで減点する
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面タップで中心からノヴァリングが1回拡がり、リングに触れた粒子を判定する。
- 青いグリントをリングで捉えると加点、赤いスパイクを巻き込むと減点してコンボが切れる。
- リングには短いクールダウンがあり、連打しても連続発射はできない。
- 青を連続で取るとコンボ倍率が伸び、同じ一撃で複数回収すると高得点になる。
- 青が中心コアへ到達すると取り逃がしになり、コンボが途切れる。

## UI（Designer）
- ボタン：スタート、再挑戦
- 表示：スコア / 残り時間 / ハイスコア / コンボ / チャージ
- 操作：タップ

## 難易度（Designer）
- 0-30秒：粒子速度は低め、青比率高めでノヴァリングの感覚を覚える導入
- 30-45秒：出現間隔を詰め、斜め流入を増やして1回で複数を狙う判断を要求する
- 45-60秒：赤スパイク比率と流速を上げ、終盤は待つ勇気が必要になる
