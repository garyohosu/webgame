# フェーズラッチ
- Date: 2026-04-10
- Slug: phase-latch

## 企画（Producer）
- 1メカニクス：タップで受け皿フェーズ（4方向）を切り替え、同位相パルスだけを受ける。
- フック（1行）：1タップ遅れるだけで連鎖崩壊する、60秒の先読みフェーズ管理。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得する。
- 負け条件：時間切れ（HP制なし）。ただし誤キャッチで大きく減点。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 上から4レーンいずれかに青Pulse/赤Noiseが落下する。
- タップするたびに受け皿が 0→1→2→3→0 の順で回転する。
- 青を現在レーンで受けると +10 点、取り逃しは -4 点。
- 赤を受けると -12 点、受けずに流すと 0 点。
- 制限時間60秒でスコア最大化を狙う。

## UI（Designer）
- ボタン：START 1個（プレイ中は非表示）
- 表示：スコア / 残り時間 / ハイスコア / 現在フェーズ
- 操作：タップ（pointerdown）で受け皿フェーズ切替

## 難易度（Designer）
- 0-30秒：落下速度ゆるめ、赤比率20%
- 30-45秒：落下速度上昇、赤比率30%
- 45-60秒：落下速度さらに上昇、同時出現率アップ、赤比率40%
