# オーロラニードル
- Date: 2026-07-16
- Slug: aurora-needle

## 企画（Producer）
- 1メカニクス：中央で左右に揺れる光針の角度に合わせてタップし、短時間だけ伸びるビームで青い粒子だけをまとめて貫いて赤い火粉を避ける
- フック（1行）：狙うのは場所ではなく、揺れ戻りの一瞬の角度そのもの。
- 勝ち条件：60秒のあいだに青い粒子をできるだけ多く撃ち抜き、ハイスコアを更新する
- 負け条件：時間切れ、または赤い火粉をビームに重ねて減点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- 光針は中央下の支点から自動で左右へ揺れ続け、プレイヤーは角度だけを見て判断する。
- タップすると現在角度に沿って短い時間だけオーロラビームが走り、触れた粒子をまとめて判定する。
- 青い粒子を貫くと加点とコンボが増え、赤い火粉を撃つと減点されてコンボが切れる。
- 粒子は画面上から落ちてくるだけなので、無理に毎回撃たず密集を待つ判断も有効。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 角度
- 操作：タップ

## 難易度（Designer）
- 0-30秒：揺れは穏やかで、青中心の導入フェーズ
- 30-45秒：揺れ速度と落下密度が上がり、先読みショットが必要になる
- 45-60秒：赤比率と落下速度が上がり、欲張った多重ヒットが危険に変わる
