# スパイラルリグ
- Date: 2026-06-20
- Slug: spiral-rig

## 企画（Producer）
- 1メカニクス：タップで回転フックの索具を INNER / OUTER に切り替え、青い貨物だけを引っ掛けて赤いジャマーを避ける。
- フック（1行）：回転のテンポは自動、触れる半径だけを選ぶから一瞬の判断がそのまま収穫になる。
- 勝ち条件：60秒のあいだに青い貨物をできるだけ多く回収してハイスコアを更新する。
- 負け条件：時間切れで終了。赤いジャマーを引っ掛けると減点され、青い貨物を逃すと連勝が切れる。
- 1プレイ時間：60秒以内

## ルール（Designer）
- フックは中心を自動回転し、タップするたびに索具の長さが INNER と OUTER で切り替わる。
- 青い貨物にフック先端を重ねると加点され、連続成功中はチェインで得点が伸びる。
- 赤いジャマーに触れると減点され、チェインは 0 に戻る。
- 貨物とジャマーは内周または外周を流れ続け、寿命が切れると消える。
- 30秒と45秒を境に、回転速度・出現密度・赤比率が上がる。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / 現在レーン
- 操作：タップ（プレイ中の画面内で INNER / OUTER 切り替え）

## 難易度（Designer）
- 0-30秒：青い貨物が多めで、内外どちらか単発出現が中心。索具切り替えのテンポを覚える導入。
- 30-45秒：同時に2つ以上流れる場面が増え、内外の切り替え判断を急がせる中盤。
- 45-60秒：赤いジャマー比率と周回速度が上がり、欲張ると誤爆しやすい終盤。
