# フラックスフォーク
- Date: 2026-05-19
- Slug: flux-fork

## 企画（Producer）
- 1メカニクス：タップで左右フォークを入れ替え、落下ノードの進路を振り分ける。
- フック（1行）：一手で「回収」と「回避」を同時に成立させる、分岐制御の気持ちよさ。
- 勝ち条件：60秒終了時にスコアを最大化する。
- 負け条件：赤ノードを回収レーンに通す（-1点）を重ねること。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 上から青/赤ノードが2レーンで落下する。
- タップで中央フォークの向きを左右同時に反転する。
- 青を下部のCOLLECT側へ通すと+1点、赤をCOLLECTへ通すと-1点。
- 逆に赤をDUMP側へ流せば+0.5ボーナス、青をDUMPに流すと0点。
- 60秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：STARTボタン1つ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdownで画面全体反応）

## 難易度（Designer）
- 0-30秒：落下速度ゆっくり、同時出現は最大2。
- 30-45秒：落下速度1.25倍、赤比率を増加。
- 45-60秒：落下速度1.5倍、連続湧き短縮で判断圧を上げる。
