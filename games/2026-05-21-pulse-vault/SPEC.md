# パルスヴォールト
- Date: 2026-05-21
- Slug: pulse-vault

## 企画（Producer）
- 1メカニクス：タップで上下レーンを切り替え、流れてくる青パルスのみ回収する。
- フック（1行）："1タップ遅れるだけで崩れる"テンポ管理が気持ちいい60秒の仕分け反射。
- 勝ち条件：60秒終了時にできるだけ高スコアを獲得する。
- 負け条件：明確なゲームオーバーはなし（赤パルス接触で減点）。
- 1プレイ時間：60秒以内

## ルール（Designer）
- プレイヤーは左端の受信機で、タップごとに上レーン/下レーンを切り替える。
- 右から流れる青パルスを受信すると +10 点。
- 赤パルスを受信すると -12 点（0点未満にはならない）。
- 取り逃した青パルスは -3 点。
- 60秒経過で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）でレーン切替

## 難易度（Designer）
- 0-30秒：出現間隔長め、弾速ゆるめ、赤パルス少なめ
- 30-45秒：出現間隔短縮、弾速上昇、赤パルス比率増加
- 45-60秒：さらに高速化、赤パルス増加で判断負荷を上げる
