# フラッシュターンスタイル
- Date: 2026-07-13
- Slug: flash-turnstile

## 企画（Producer）
- 1メカニクス：中央ゲートをタップで一瞬だけ通電し、3レーンを横切る青い印章だけをまとめて焼き付ける
- フック（1行）：短い通電窓に複数レーンを重ねて抜く、料金所みたいな気持ちよさがある。
- 勝ち条件：60秒のあいだに青いルーン印章をできるだけ多く焼き付け、ハイスコアを更新する
- 負け条件：時間切れ、または赤いジャム印章を通電中に巻き込んで減点する
- 1プレイ時間：60秒以内

## ルール（Designer）
- 3本のレーンを左右から印章が流れ、中央のターンスタイルを横切っていく。
- タップすると中央ゲートが短時間だけ発光し、その範囲に入った印章をまとめて判定する。
- 青いルーン印章は得点になり、1回の発光で連続ヒットするとコンボが伸びる。
- 赤いジャム印章を巻き込むと大きく減点され、コンボが切れて短いクールダウンに入る。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 状態
- 操作：タップ

## 難易度（Designer）
- 0-30秒：印章の速度は穏やかで、青印章中心のリズムを掴む導入フェーズ
- 30-45秒：流速と同時出現数が増え、左右両方向からの重なりを見てタップする中盤フェーズ
- 45-60秒：赤印章の比率と移動速度が上がり、欲張るほど危険な終盤フェーズ
