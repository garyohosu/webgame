# フレアスロープ
- Date: 2026-06-24
- Slug: flare-slope

## 企画（Producer）
- 1メカニクス：タップで炉床スロープの傾きを LEFT / RIGHT に反転し、青いフレアだけを左カップへ、赤いスラグを右ベントへ流す。
- フック（1行）：落ちてきた瞬間ではなく、着地して転がる未来を読む一本勝負の仕分けアクション。
- 勝ち条件：60秒のあいだに青いフレアをできるだけ多く左カップへ送り込み、ハイスコアを更新する。
- 負け条件：時間切れで終了。青を右へ逃がす、または赤を左に流すと減点される。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 粒子は上から落ち、中央の傾斜炉床に着地すると現在の傾きに沿って左右どちらかへ滑る。
- プレイ中に画面をタップすると炉床の傾きが LEFT / RIGHT に切り替わる。
- 青いフレアを左カップへ流すと加点し、連続成功でコンボが伸びる。
- 赤いスラグを右ベントへ流せば安全処理。青を右へ逃がすか赤を左へ落とすと減点とコンボ切れ。
- 30秒と45秒で落下頻度・滑走速度・赤比率が上昇し、切り替え判断が忙しくなる。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / 傾き / コンボ
- 操作：タップで LEFT / RIGHT 切り替え

## 難易度（Designer）
- 0-30秒：青多め、滑走も緩やか。左右の出口と慣性を覚える導入。
- 30-45秒：赤スラグが増え、着地直後の反転判断が必要になる中盤。
- 45-60秒：滑走速度と連続出現が最大化し、1回の誤判断が連鎖しやすい終盤。
