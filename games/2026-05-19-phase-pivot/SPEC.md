# フェーズピボット
- Date: 2026-05-19
- Slug: phase-pivot

## 企画（Producer）
- 1メカニクス：タップで回転する判定アームの角度を固定して、青ノードだけを回収する。
- フック（1行）：回し続けるか、今止めるか——一手の判断で連続得点が伸びる60秒。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得する。
- 負け条件：時間切れ（ゲームオーバーはなく、減点ミスあり）。
- 1プレイ時間：60秒

## ルール（Designer）
- タップでアームが「回転/停止」を切り替える。
- ノードは中心へ向かって流れ、判定リングに触れた瞬間に判定される。
- 判定角度に青ノードが入っていれば得点、赤ノードなら減点。
- 見逃しは減点なし、赤ヒットだけを避けるのが重要。
- 60秒終了で結果表示し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア / 状態（RUN/HOLD）
- 操作：タップ（pointerdown）で回転状態を切替

## 難易度（Designer）
- 0-30秒：ノード速度は標準、赤比率低め。
- 30-45秒：ノード速度1.2倍、赤比率上昇。
- 45-60秒：ノード速度1.45倍、同時出現が増えて判断密度上昇。
