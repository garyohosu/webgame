# ソーンブルーム
- Date: 2026-06-19
- Slug: thorn-bloom

## 企画（Producer）
- 1メカニクス：タップで中心から収穫パルスを放ち、青い花芽だけをリングで刈り取り、赤い棘を巻き込まない。
- フック（1行）：一度のタップで何を咲かせ、何を傷つけるかが決まる、欲張るほど危ない収穫ゲーム。
- 勝ち条件：60秒のあいだに青い花芽をできるだけ多く収穫してハイスコアを更新する。
- 負け条件：時間切れで終了。赤い棘にパルスを当てると大きく減点し、青い花芽を逃すとコンボが切れる。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面をタップすると、中心から1本の収穫リングが外側へ広がる。
- リングに触れた青い花芽は収穫成功で加点、連続成功中はコンボで得点が伸びる。
- リングが赤い棘に触れると減点され、コンボが0に戻る。
- 花芽と棘は外周から渦を描きながら中心へ近づき、中心に入ると消える。
- 30秒と45秒を境に、出現密度・移動速度・赤い棘の比率が上がる。

## UI（Designer）
- ボタン：スタート、再挑戦、戻るリンク
- 表示：スコア / 残り時間 / ハイスコア / コンボ
- 操作：タップ（プレイ中の画面内でパルス発射）

## 難易度（Designer）
- 0-30秒：青い花芽が多めで、単発出現中心。パルスの当て勘を覚える導入。
- 30-45秒：2連出現や渦の揺れが増え、リング1本で複数を狙う判断が必要になる。
- 45-60秒：赤い棘の比率と移動速度が上がり、欲張ると事故る高密度終盤になる。
