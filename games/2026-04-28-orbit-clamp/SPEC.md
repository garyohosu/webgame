# オービットクランプ
- Date: 2026-04-28
- Slug: orbit-clamp

## 企画（Producer）
- 1メカニクス：回転するクランプの開閉角に合わせてタップし、青ノードだけを捕捉する
- フック（1行）：回転のリズムを読み切って「今閉じる」を連続成功させる、60秒の集中制御。
- 勝ち条件：60秒終了時にできるだけ高スコアを獲得する
- 負け条件：赤ノードを捕捉して減点を重ねる（ゲームオーバーはなし）
- 1プレイ時間：60秒以内

## ルール（Designer）
- ノードは円周上を回転しながら判定リングへ入ってくる。
- タップ（pointerdown）でクランプを短時間CLOSEし、リング内ノードを捕捉判定する。
- 青ノード捕捉で加点、赤ノード捕捉で減点、何もない時のタップは軽い減点。
- CLOSE中は連打しても再発動しない（誤タップ耐性）。
- 60秒経過で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：START / RESTART
- 表示：スコア / 残り時間 / ハイスコア / 状態メッセージ
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：回転速度は中、赤ノード比率20%
- 30-45秒：回転速度アップ、赤ノード比率30%
- 45-60秒：回転速度さらにアップ、赤ノード比率40%
