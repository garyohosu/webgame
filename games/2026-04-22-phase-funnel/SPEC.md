# フェーズファンネル
- Date: 2026-04-22
- Slug: phase-funnel

## 企画（Producer）
- 1メカニクス：タップで3つのファンネル（左・中央・右）を巡回切替し、落下ノードを受ける
- フック（1行）：1タップで受け皿が回るだけなのに、終盤は先読みしないと赤ノードが刺さる
- 勝ち条件：60秒終了時にスコアをできるだけ高くする
- 負け条件：時間切れ（赤ノード接触で減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- タップ（pointerdown）ごとにアクティブファンネルが左→中央→右→左…と切り替わる。
- 青ノードをアクティブファンネルで受けると +1 点。
- 赤ノードをアクティブファンネルで受けると -2 点（最低0点）。
- 取り逃したノードはスコア変化なし。
- 60秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア / 状態メッセージ
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：落下速度は標準、赤ノード比率は低め。
- 30-45秒：落下速度を上げ、同時出現間隔を短縮。
- 45-60秒：さらに速度上昇、赤ノード比率を増やして判断負荷を上げる。
