# カラーカレント
- Date: 2026-03-10
- Slug: color-current

## 企画（Producer）
- 1メカニクス：タップでゲート色（ブルー/ピンク）を切り替え、同色の流体粒子だけを通す。
- フック（1行）：1タップで世界の色相を反転し、通す/弾くを瞬時に判断する60秒。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得する。
- 負け条件：ミスマッチ粒子の通過でライフが0になる。
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面下のゲート色はタップごとにブルー⇄ピンクで切り替わる。
- 上から落ちる粒子は青/桃の2色で、ゲートと同色なら +1 点。
- 異色の粒子を通すとライフ -1（初期3）。
- ライフが0になるか、60秒経過でゲーム終了。
- ハイスコアは端末に保存し、次回以降の目標にする。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア / ライフ / 現在ゲート色
- 操作：タップ（pointerdown）でゲート色切替

## 難易度（Designer）
- 0-30秒：粒子の落下速度はゆるめ、同色率高め。
- 30-45秒：落下速度アップ、異色率を増加。
- 45-60秒：落下速度さらに上昇、同時出現が増える。
