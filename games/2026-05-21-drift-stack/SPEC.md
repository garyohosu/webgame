# ドリフトスタック
- Date: 2026-05-21
- Slug: drift-stack

## 企画（Producer）
- 1メカニクス：タップで左右レーンを切り替え、落下キューブの着地位置を合わせて積む
- フック（1行）：1タップで未来の着地が変わる、判断が連鎖する60秒スタック。
- 勝ち条件：60秒終了時にできるだけ高得点を獲得する
- 負け条件：なし（赤キューブ誤取得で減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- キューブは上から落下し、左右どちらかのレーンに着地する。
- タップ（pointerdown）でプレイヤーの受け位置を左/右へ切り替える。
- 青キューブを受けると+10点、赤キューブを受けると-12点。
- 連続で青キューブを受けるとコンボが伸び、得点ボーナスが加算される。
- 取り逃しは0点でコンボが切れる。60秒で終了。

## UI（Designer）
- ボタン：START / REPLAY（終了時）
- 表示：スコア / 残り時間 / ハイスコア / コンボ
- 操作：タップで左右切替

## 難易度（Designer）
- 0-30秒：通常速度、赤比率20%
- 30-45秒：落下速度1.2倍、赤比率30%
- 45-60秒：落下速度1.4倍、赤比率38%、同時2個出現率アップ
