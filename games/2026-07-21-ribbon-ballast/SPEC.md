# リボンバラスト
- Date: 2026-07-21
- Slug: ribbon-ballast

## 企画（Producer）
- 1メカニクス：タップで水槽全体の浮力リボンを UP / DOWN に反転し、流れていく粒の高さをまとめて変える
- フック（1行）：一度の反転で群れの運命を上下に塗り替える、静かな大渋滞さばき。
- 勝ち条件：60秒のあいだに青いバブルを上ハッチへ、赤いシンダーを下ベントへできるだけ多く送り込んでハイスコアを更新する
- 負け条件：時間切れ、または青を下へ落とし赤を上へ抜いて減点を重ねる
- 1プレイ時間：60秒以内

## ルール（Designer）
- 左から流れ込む青いバブルと赤いシンダーを見て、画面タップで浮力リボンを UP / DOWN に切り替える。
- 粒は右へ進み続けるが、現在の浮力に応じて上下へ曲がり、右端の上ハッチか下ベントへ抜けていく。
- 青を上ハッチへ送ると大きく加点してコンボ加算、赤を下ベントへ逃がすと小加点になる。
- 青を下ベントへ落とす、または赤を上ハッチへ通すと減点されてコンボが切れる。
- 60秒終了時のスコアで勝負し、ハイスコアは localStorage に保存する。

## UI（Designer）
- ボタン：スタート、リトライ
- 表示：スコア / 残り時間 / ハイスコア / コンボ / 浮力モード
- 操作：タップ

## 難易度（Designer）
- 0-30秒：流速は穏やかで、青多めの単発ウェーブ中心
- 30-45秒：出現密度と横流れが上がり、赤の混ざる列が増える
- 45-60秒：粒の速さと赤比率がさらに上がり、反転の遅れがそのまま失点につながる
