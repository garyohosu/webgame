# ドリフトゲート
- Date: 2026-04-26
- Slug: drift-gate

## 企画（Producer）
- 1メカニクス：左右に流れるビーコンを、揺れるゲート帯の中でタップ捕捉するタイミングアクション
- フック（1行）：動く2つの位相が噛み合う一瞬を叩き続ける、集中60秒。
- 勝ち条件：60秒終了時にできるだけ高スコアを獲得する
- 負け条件：時間切れ（ゲームオーバー）
- 1プレイ時間：60秒以内

## ルール（Designer）
- スタート後、ビーコンが左右に往復し続ける。
- ゲート帯もゆっくり左右へドリフトする。
- 画面をタップした瞬間、ビーコン中心がゲート内なら成功で +1 点。
- ゲート外でタップすると失敗で -1 点（最低 0 点）。
- 成功時はゲート幅がわずかに縮み、終盤ほど判定がシビアになる。

## UI（Designer）
- ボタン：スタートボタン 1つ
- 表示：スコア / 残り時間 / ハイスコア / フィードバック（HIT/MISS）
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：ビーコン中速、ゲート広め、ゲート移動ゆるやか
- 30-45秒：ビーコン速度 1.25 倍、ゲート幅を段階縮小
- 45-60秒：ビーコン速度 1.5 倍、ゲート幅さらに縮小、ゲート移動速度も上昇
