# オービットラッチ
- Date: 2026-05-20
- Slug: orbit-latch

## 企画（Producer）
- 1メカニクス：タップで回転カーソルを「一時停止→再始動」し、青ノードの位置で止める
- フック（1行）：止める勇気より、止めない勇気がスコアを伸ばす。
- 勝ち条件：60秒終了時にできるだけ高いスコアを獲得する
- 負け条件：時間切れ（ゲームオーバーはなし、赤誤爆で減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 回転するカーソルがリング上を周回する。
- リング上には青ノード（+10）と赤ノード（-12）が出現する。
- 画面タップ（pointerdown）でカーソルを0.24秒だけ停止できる。
- 停止中にカーソルがノードへ重なっていれば即判定される。
- 60秒で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：START / RETRY
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：回転速度標準、青:赤=7:3、ノード少なめ
- 30-45秒：回転速度1.2倍、青:赤=6:4
- 45-60秒：回転速度1.45倍、青判定半径やや縮小、赤の出現率上昇
