# シジルスナップ
- Date: 2026-03-20
- Slug: sigil-snap

## 企画（Producer）
- 1メカニクス：中央の目標シジルと同じマークのタイルだけを瞬時にタップする
- フック（1行）：次々落ちる紋章から「今の正解」だけを抜く、脳の切替速度勝負。
- 勝ち条件：60秒でできるだけ高いスコアを獲得する
- 負け条件：時間切れ（ライフ制なし）
- 1プレイ時間：60秒以内

## ルール（Designer）
- 画面上部に「TARGET」シジルが表示される。
- 落下するシジルタイルをタップし、TARGETと一致すれば+10点。
- 不一致タイルをタップすると-6点。
- タイルは放置すると消え、ペナルティなし。
- TARGETは一定時間ごとに切り替わる。

## UI（Designer）
- ボタン：スタートボタン1つ
- 表示：スコア / 残り時間 / ハイスコア / 現在のTARGET
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：出現間隔900ms、落下速度ゆるめ、TARGET切替6秒
- 30-45秒：出現間隔700ms、速度上昇、TARGET切替5秒
- 45-60秒：出現間隔520ms、速度さらに上昇、TARGET切替4秒
