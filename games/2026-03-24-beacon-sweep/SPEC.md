# ビーコンスイープ
- Date: 2026-03-24
- Slug: beacon-sweep

## 企画（Producer）
- 1メカニクス：左右に自動往復するビーコンを、タップで短時間ブレーキして落下ターゲットを迎撃する
- フック（1行）：動き続ける照準を一瞬止める判断だけで、60秒の集中が止まらない。
- 勝ち条件：60秒終了時にスコアをできるだけ伸ばし、ハイスコア更新を狙う
- 負け条件：即時ゲームオーバーはなし（誤迎撃で減点）
- 1プレイ時間：60秒以内

## ルール（Designer）
- ビーコンは下部を左右に自動移動し、タップで約0.22秒だけ停止する。
- 落下する青ターゲットをビーコン下で受けると +1 点。
- 赤ノイズを受けると -2 点（最低0点）。
- タップ位置は問わず、毎回「停止→再移動」を繰り返す。
- 60秒経過で終了し、ハイスコアを保存する。

## UI（Designer）
- ボタン：Start / Retry（同一ボタンで状態切替）
- 表示：スコア / 残り時間 / ハイスコア
- 操作：タップ（pointerdown）

## 難易度（Designer）
- 0-30秒：落下速度は標準、赤ノイズ比率低め
- 30-45秒：落下速度上昇、同時出現数が増える
- 45-60秒：落下速度さらに上昇、赤ノイズ比率増加
